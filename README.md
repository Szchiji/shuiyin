# 水印小程序 🖼️

基于 **FastAPI + Pillow + MoviePy** 构建的水印添加工具，支持图片和视频。

---

## 功能列表

- 支持图片格式：JPG / PNG / WebP
- 支持视频格式：MP4 / MOV
- 文字水印（支持中文）
- Logo 图片水印
- 五种位置：左上 / 右上 / 左下 / 右下 / 居中
- 透明度调节（0 ~ 100）
- 全图平铺水印
- 简洁中文前端页面，无需外部 CDN 依赖
- Telegram 私信预填：转发消息后返回可复制用户 ID 和预填链接

---

## Telegram 私信预填

1. 把对方的一条消息转发给机器人
2. 识别成功时回复：

```
对方：张三  @zhangsan
ID：123456789

点下方链接打开私聊，文案已预填，需自己点发送。

https://t.me/zhangsan?text=……
```

3. ID 为等宽代码，点击可复制。链接只会预填，不会自动发送。
4. 对方隐藏转发来源时，请再发送 `@用户名` 或 `https://t.me/用户名`。
5. 没有公开用户名时无法生成预填链接，仍会尽量给出可复制 ID 和文案。

### 新命令

| 命令 | 说明 |
|------|------|
| `/contact` | 查看私信预填说明和当前文案 |
| `/contact_tpl` | 设置个人预填文案 |
| `/link` | 在群里回复某人消息后生成预填链接 |
| `/contact_set` | 管理员设置系统默认预填文案 |

`WEBHOOK_URL` 设置后，回调地址为 `{WEBHOOK_URL}/telegram-webhook`，Token 不再出现在 URL 里。
